# Statistics Notes

Complete statistics notes for the data-science-roadmap, written in a simple definition-first exam style: a plain intro, a bold one-line definition, an "in simple words" restatement, key points, types, examples, difference tables, and notes.

## Contents

1. [Foundations](01-foundations.md) - what is statistics, population vs sample, census vs sample, parameters vs statistics, types of data, measurement scales
2. [Descriptive Statistics](02-descriptive-statistics.md) - mean, median, mode, range, variance, standard deviation, percentiles, quartiles, IQR, skewness, kurtosis
3. [Probability](03-probability.md) - fundamentals, sample space, events, probability rules, conditional probability, independent and dependent events, Bayes theorem, joint and marginal probability, expected value, law of large numbers
4. [Distributions](04-distributions.md) - uniform, normal, standard normal, binomial, Poisson, exponential
5. [Inferential Statistics](05-inferential-statistics.md) - sampling, sampling methods, sampling error and bias, central limit theorem, point vs interval estimate, confidence intervals, margin of error, bootstrapping, MLE, hypothesis testing, one vs two-tailed tests, p-value, type I and II errors, statistical power, degrees of freedom
6. [Statistical Tests](06-statistical-tests.md) - z-test, t-test, paired t-test, ANOVA, chi-square, Mann-Whitney U, Wilcoxon, Kolmogorov-Smirnov
7. [Relationships](07-relationships.md) - correlation, Pearson, Spearman, covariance, multicollinearity
8. [Experiments](08-experiments.md) - A/B testing, multivariate testing, experiment design, randomization, causal inference basics
9. [Exploratory Data Analysis (EDA)](09-exploratory-data-analysis.md) - load and inspect, missing values, imputation, visualization (histogram, pairplot, heatmap, Q-Q plot), scaling, train/test split, KNN model, evaluation (confusion matrix, precision, recall, F1, ROC AUC), grid search

## Notation used

- Population values (parameters) use Greek letters: mu (mean), sigma (standard deviation), p (proportion).
- Sample values (statistics) use English letters: x-bar (mean), s (standard deviation), p-hat (proportion).
